HOW TO PLAY
───────────
Open index.html in any modern web browser.
No server or install required.

OBJECTIVE
─────────
Restore the signal by creating a continuous path
of active nodes from SOURCE (SRC) to TARGET (DST).

NODE TYPES
──────────
  SRC  — Source node. Always active. Cannot be moved.
  DST  — Destination. Reach this to win the level.
  ○    — Relay node. Click to activate (free).
  ✗    — Corrupted node. Click to repair (costs 1 repair charge).
  ■    — Dead node. Cannot be activated.

CONTROLS
────────
  Click relay node      → Activate / deactivate
  Click corrupted node  → Repair (uses 1 charge)
  RESET LEVEL           → Start the level over
  ABORT MISSION         → Return to title screen

LEVELS
──────
  01 — SECTOR ALPHA   (5×5 grid, 3 repairs)
  02 — SECTOR BETA    (5×5 grid, 2 repairs)
  03 — SECTOR GAMMA   (6×6 grid, 3 repairs)
  04 — SECTOR DELTA   (6×6 grid, 3 repairs)
  05 — SECTOR OMEGA   (7×7 grid, 4 repairs)

TIPS
────
• You don't need to light up every node — just find
  any valid path from SRC to DST.
• Corrupted nodes on key routes may force you to
  plan your repair budget carefully.
• Clicking an active (free) relay toggles it off,
  so you can always adjust your route.
• Repaired nodes stay repaired — use them wisely.

TECH
────
Single HTML file. No dependencies, no server.
Requires internet only for Google Fonts (cosmetic).
Works offline with system monospace fallback fonts.
